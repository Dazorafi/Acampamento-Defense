🏰 Tower Defense: Defesa do Acampamento

Um jogo estilo Tower Defense desenvolvido totalmente em código Python, com o objetivo de defender um acampamento contra ondas de inimigos.

📌 Sobre o Projeto
O Defesa do Acampamento é um jogo criado como trabalho acadêmico, desenvolvido do zero utilizando Python (full code), sem uso de engines prontas.
O projeto tem como foco aplicar conceitos fundamentais de programação, como:
Estruturação e organização de código
Lógica de jogos
Manipulação de eventos
Controle de estados
Interação com o usuário

No jogo, o jogador deve posicionar torres estrategicamente para impedir que inimigos alcancem o acampamento, utilizando estratégia e gerenciamento de recursos.

🕹️ Gameplay
🎯 Objetivo: Defender o acampamento contra ondas de inimigos
🧠 Estratégia: Posicionar armadilhas nos locais certos ou recuperar pontos de vida ficando próximo da barraca
💰 Recursos: Gerenciamento de pontos/moedas para construir torres
👾 Inimigos: Ondas progressivas com aumento de dificuldade
🏁 Condição de derrota: Inimigos invadem o acampamento
🏆 Condição de vitória: Sobreviver às ondas
